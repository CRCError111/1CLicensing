# Система лицензирования расширений конфигураций для 1С

## Назначение

Система предназначена для защиты расширений конфигураций 1С, распространяемых через сайт infostart.ru. Обеспечивает:

- Демо-доступ на 14 дней
- Генерацию запроса лицензии пользователем
- Формирование ответа разработчиком
- Активацию полной версии

## Требования

- Платформа 1С:Предприятие 8.3.10 и выше
- Только встроенные средства 1С (без стороннего ПО)
- Общий модуль с паролем

## Структура файлов

```
LicenseModule.bsl      - Основной модуль лицензирования
LicenseGenerator.bsl   - Генератор лицензий для разработчика
README.md             - Эта документация
```

## Установка

### Шаг 1: Создание общего модуля

1. В конфигураторе создайте общий модуль с именем `Лицензирование`
2. Установите галочки:
   - ✅ Сервер
   - ✅ Клиент
   - ✅ Внешнее соединение
   - ❌ Глобальный (не рекомендуется)
3. **Установите пароль на модуль** (правой кнопкой → Свойства → Пароль)

### Шаг 2: Размещение кода

Скопируйте содержимое файла `LicenseModule.bsl` в созданный общий модуль.

### Шаг 3: Создание таблицы в базе данных (опционально)

Для хранения лицензии в БД создайте регистр сведений или справочник:

```bsl
// Имя таблицы: ИнфоРасширениеЛицензии
// Реквизиты:
// - Данные (Строка, 1000)
```

Или используйте только файл и реестр (таблица не обязательна).

### Шаг 4: Настройка констант

В начале серверной части модуля измените при необходимости:

```bsl
Перем Лице_КлючПроверки = "L1C3NS3_K3Y_2024_X7Y9Z2A4B6"; // Ваш уникальный ключ
Перем Лице_СрокДемо = 14; // Дней демо-доступа
```

**Важно:** Ключ должен совпадать в модуле и генераторе!

## Использование в расширении

### Проверка доступа к функционалу

```bsl
// В любом месте кода расширения
Если Лицензирование.ПолученДоступКФункционалу() Тогда
    // Выполняем защищенный код
    МояЗащищеннаяФункция();
Иначе
    // Показываем сообщение о необходимости лицензии
    Сообщить("Функционал недоступен. Требуется лицензия.");
КонецЕсли;
```

### Получение статуса лицензии

```bsl
Статус = Лицензирование.ПолучитьСтатусЛицензии();

Если Статус.Активна Тогда
    Если Статус.Код = "trial" Тогда
        Сообщение = Статус.Сообщение; // "Демо-режим активен. Осталось дней: X"
    Иначе
        Сообщение = "Лицензия активна";
    КонецЕсли;
Иначе
    Сообщение = Статус.Сообщение; // Причина блокировки
КонецЕсли;
```

### Формирование запроса лицензии

```bsl
// Когда демо-период завершен
ТекстЗапроса = Лицензирование.СформироватьЗапросЛицензии();

// Пользователь копирует этот текст и отправляет разработчику
// Можно показать в диалоге или сохранить в файл
```

### Активация лицензии

```bsl
// Пользователь получает от разработчика текст ответа
ТекстОтвета = "..."; // Текст из письма разработчика

Попытка
    Лицензирование.ЗагрузитьОтветЛицензии(ТекстОтвета);
    Сообщить("Лицензия успешно активирована!");
Исключение
    Сообщить("Ошибка активации: " + ОписаниеОшибки());
КонецПопытки;
```

## Работа разработчика

### Генерация лицензии

1. Получите от пользователя текст запроса
2. Скопируйте `LicenseGenerator.bsl` в любую базу 1С (можно в отдельную)
3. Запустите в режиме предприятия
4. Выполните код:

```bsl
ТекстЗапросаОтПользователя = "..."; // Вставьте текст от пользователя
ГодНачала = 2024;
ГодОкончания = 2025;

Результат = СформироватьЛицензию(ТекстЗапросаОтПользователя, ГодНачала, ГодОкончания);

// Результат содержит текст для отправки пользователю
// Скопируйте и отправьте пользователю
```

### Пример ответа пользователю

```
=== ОТВЕТ С ЛИЦЕНЗИЕЙ ===
Скопируйте этот текст и передайте пользователю:

UmVTUE9OU0VfTElDRU5TRXxURVNUX0hXSUR8MjAyNHwyMDI1fEFCQzEyMzQ1Njc4OTB8...

Лицензия выдана для HWID: TEST_HWID
Период действия: 2024 - 2025
=========================
```

## Уровни защиты

### 1. Пароль на модуль
Стандартный механизм 1С защищает исходный код от просмотра.

**Рекомендация:** Используйте сложный пароль (минимум 12 символов).

### 2. HWID-привязка
Лицензия привязывается к:
- Имени компьютера
- Пути к базе данных
- Имени информационной базы
- Пользователю ОС

При копировании базы на другой компьютер лицензия не сработает.

### 3. Криптография в рамках 1С
- Полиномиальное хеширование (два независимых хеша)
- XOR-шифрование с циклическим ключом
- Base64-кодирование
- Контрольные суммы для всех данных

### 4. Множественное хранение
Лицензия сохраняется в трех местах:
1. Файл в каталоге данных (`infostart_license.dat`)
2. Реестр Windows (только Windows)
3. Таблица в базе данных

Это усложняет удаление лицензии.

### 5. Контроль целостности модуля
Проверка наличия ключевых функций в модуле.

### 6. Проверка на отладку
Косвенная проверка времени выполнения операций.

### 7. Обфускация кода (рекомендации)

Перед публикацией расширения выполните:

1. **Переименуйте переменные** в короткие имена:
   ```bsl
   // Было
   Перем Лице_КлючПроверки = "...";
   
   // Стало
   Перем ЛКП = "...";
   ```

2. **Удалите комментарии** из рабочей версии

3. **Добавьте ложный код**:
   ```bsl
   // Ложная ветка для запутывания
   Если Ложь Тогда
       // Код который никогда не выполнится
       НеСуществующаяФункция();
   КонецЕсли;
   ```

4. **Разбейте на несколько модулей** и вызывайте друг друга

### 8. Параллельные проверки
Кэширование результата на 1 минуту снижает нагрузку, но каждый вызов выполняет полную проверку.

## Оценка взломостойкости

Для взлома системы злоумышленнику потребуется:

1. **Обойти пароль модуля** (1-3 дня)
   - Подбор пароля
   - Использование уязвимостей платформы

2. **Понять логику работы** (3-7 дней)
   - Анализ алгоритма HWID
   - Расшифровка формата лицензии

3. **Найти ключ проверки** (2-5 дней)
   - Поиск в коде
   - Динамический анализ

4. **Подделать лицензию** (5-10 дней)
   - reverse engineering хеш-функции
   - Генерация валидной подписи

5. **Обойти множественные проверки** (3-7 дней)
   - Поиск всех мест проверок
   - Модификация кода

6. **Тестирование и отладка** (3-5 дней)
   - Проверка на разных версиях платформы
   - Обход дополнительных защит

**Итого: 17-37 рабочих дней (более месяца)**

## Ограничения системы

### Известные ограничения

1. **Копирование диска целиком**
   - При полном клонировании диска лицензия сохранится
   - Это компромисс между удобством и защитой
   - Рекомендуется дополнительно использовать привязку к сетевому имени

2. **Изменение системного времени**
   - Пользователь может изменить дату для продления демо
   - Частично компенсируется проверкой даты начала лицензии

3. **Отсутствие криптографии ГОСТ**
   - Используются только встроенные средства 1С
   - Для серьезной защиты требуется внешняя криптография

### Рекомендации по усилению

1. **Серверная проверка**
   - Добавьте онлайн-проверку лицензий на вашем сервере
   - Требуйте периодического подключения к интернету

2. **Привязка к GUID базы**
   - Используйте `УникальныйИдентификаторИнформационнойБазы()`
   - Это усложнит перенос лицензии

3. **Несколько уровней проверки**
   - Проверяйте лицензию в разных местах кода
   - Используйте разные алгоритмы проверки

4. **Логирование попыток взлома**
   - Сохраняйте информацию о неудачных проверках
   - Отправляйте отчеты разработчику

## Типовые сценарии

### Сценарий 1: Демо-режим

```
День 0: Пользователь установил расширение
        → Автоматически начинается демо-период

День 1-13: Полный доступ ко всем функциям

День 14: Последние предупреждения

День 15: Демо-период завершен
        → Пользователь формирует запрос
        → Отправляет разработчику
        → Получает ответ
        → Активирует лицензию
```

### Сценарий 2: Повторная установка

```
Пользователь переустановил систему
→ Изменился путь к базе или имя компьютера
→ HWID не совпадает
→ Требуется новая лицензия

Решение: Пользователь отправляет новый запрос
```

### Сценарий 3: Перенос базы

```
База перенесена на другой сервер
→ HWID изменился
→ Старая лицензия не работает

Решение: 
1. Получить новый HWID
2. Отправить запрос разработчику
3. Получить новую лицензию
```

## Диагностика проблем

### Ошибка "Лицензия не для этого компьютера"

**Причина:** Изменился HWID

**Решение:**
1. Проверьте имя компьютера
2. Проверьте путь к базе данных
3. Запросите новую лицензию

### Ошибка "Неверная контрольная сумма"

**Причина:** Текст лицензии был изменен

**Решение:**
1. Копируйте текст полностью, без изменений
2. Не редактируйте текст ответа
3. Запросите новый ответ у разработчика

### Ошибка "Модуль поврежден"

**Причина:** Изменен код модуля

**Решение:**
1. Восстановите оригинальный код модуля
2. Не модифицируйте защищенный модуль

## FAQ

**В: Можно ли использовать одну лицензию на нескольких компьютерах?**

О: Нет, лицензия привязана к уникальному HWID. Для каждого компьютера нужна отдельная лицензия.

**В: Что будет если пользователь изменит системное время?**

О: Демо-период считается от даты первой установки, которая сохраняется в файле. Изменение времени не поможет.

**В: Как обновить лицензию?**

О: Выпустите новую лицензию с новыми датами. Пользователь просто загрузит её поверх старой.

**В: Можно ли сделать бессрочную лицензию?**

О: Да, установите год окончания на отдаленное будущее (например, 2099).

**В: Работает ли система на Linux-сервере?**

О: Да, но реестр Windows использоваться не будет. Лицензия сохранится в файл и БД.

**В: Как защитить сам генератор лицензий?**

О: Размещайте генератор на своем сервере, не передавайте его пользователям.
